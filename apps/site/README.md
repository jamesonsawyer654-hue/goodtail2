# Good Tail Co. — project files

- `config.js` — store details, products, prices and PayPal links (the data the site is built from)
- `src/build.js` + `src/style.css` — build the website into `../good-tail-site/` (`node src/build.js ../good-tail-site`, then copy `images/`, `p/`, `v/`)
- `images/`, `p/` (Pinterest pins), `v/` (videos) — media that's published with the site
- `PLAYBOOK.md` — how the business runs · `automation/` — autopilot + email routine · `marketing/` — content plan, pins, Instagram kit
- Live site: https://goodtailco.netlify.app
