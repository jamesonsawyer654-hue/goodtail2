# Instagram setup (about 3 minutes)

Instagram needs **you** to create the account (phone number and a real person). Everything else is ready.

## 1. Create the account
- **Username** (pick the first that's free): `goodtailco` · `goodtail.co` · `shopgoodtail` · `goodtailpets`
- **Name:** Good Tail Co. | Pet Care
- **Profile photo:** `marketing/profile-picture.png`
- Then Settings → *Account type and tools* → **Switch to professional account → Business** → category **Pet Supplies**.

## 2. Bio (copy and paste)
```
Small upgrades for happier pets 🐾
Shedding, pet hair & bath time, solved
🚚 Free US shipping · 30-day returns
👇 Shop
```
**Link:** https://goodtailco.netlify.app

## 4. Reels
The 5 videos in `/v/` (also at goodtailco.netlify.app/v/brush.mp4 and so on) are Reels-ready. Add a trending sound in the app, then use the matching captions from `marketing/30-DAY-CONTENT-PLAN.md`.

## 5. Story highlights
Post each image in `highlights/` as a story, then save it to a highlight named **Shop**, **Shipping**, **FAQ** or **Tips** and set the same image as the cover.
